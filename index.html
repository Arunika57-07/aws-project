Project Summary

This site runs on a Free Tier EC2 instance inside a custom VPC. Static assets are synced from Amazon S3, and the instance reads S3 through an IAM role with no stored access keys.

  • VPC with public subnet, internet gateway and route table
  • EC2 t3.micro running Apache on Ubuntu
  • CloudWatch alarms with SNS email alerts
  • EBS snapshot backup and AWS Budgets cost alerts
